# Legal OS File Delivery and Archive Workspace

Generic source-locked workflow for conversion, packaging and archive. Preserve originals, semantic content, version relations and an auditable manifest. DOCX/XLSX source correctness is primary; visual inspection is conditional under [`native-office-quality-gate.md`](native-office-quality-gate.md). Substantive changes route to the responsible primary legal workflow. Sending/submitting/signing/publishing/pushing require separate authorization.
