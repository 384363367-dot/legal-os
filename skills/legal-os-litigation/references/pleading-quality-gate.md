# Pleading quality gate

Pass only when each material fact and requested relief/defence is supported by supplied material, legal propositions are tied to current verified authority, and the document has passed structured checks. Native preview/native-application inspection is auxiliary and risk-proportionate only when requested or when a concrete layout defect exists; it is not a default release prerequisite for a structurally valid DOCX.

For a claimant's initial complaint, arbitration application, payment-order application or equivalent first request, also confirm that:

- the document maintains one represented-party stance and closes the supported chain from performance to due obligation, breach and relief;
- it does not invent or volunteer a hypothetical opponent defence, evidence roadmap, proof deficiency, burden-allocation plan or adjudicator investigation plan;
- it does not present an unverified favourable fact as established or disclose internal risk, fallback or response strategy;
- every adverse proposition, compatible alternative position or conditional formulation admitted to the external document satisfies R14 and has a recorded source and function;
- case use is necessary, source-verified and claim-serving, while directly relevant contrary material remains recorded in the internal authority package;
- investigation, evidence-production, hearing and evidence-comment functions have not been mixed into the initial pleading unless the selected procedure expressly requires them.

A conditional-language match triggers `REVIEW_REQUIRED`, not automatic deletion or automatic failure. Remove unsupported or unnecessary text from the external artifact and preserve useful analysis in the correct internal artifact.

A complaint, application or answer also requires a separately generated evidence catalogue whose numbering, evidence names and proof purposes match the pleading's factual structure; the pleading itself must not contain an independent “证据和证据来源” chapter. If evidence is incomplete, label the catalogue `待补证 / 内部草稿` and keep the release state blocked or draft-only. Fail or hold for review when identity, amount, date, forum, case number, procedural posture, core evidence, or cross-artifact mapping conflicts. Treat font, pagination, table or print-layout findings as blockers only when a requested auxiliary visual check or reliable structural inspection establishes a material source defect; a renderer or font-environment issue alone does not block a structurally valid DOCX. Labour/personnel arbitration pleadings fail if they request arbitration costs from the other party. Keep drafting, internal review, sending, filing, and signing as separate authorization states.
