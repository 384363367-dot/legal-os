# Case research → litigation strategy handoff

Use this handoff only after `cn-case-hub` has produced verified core cases and decision-fork variables.

## Action matrix

| Decision-fork variable | Matter fact/status | Supporting evidence | Adverse/contradictory evidence | Evidence gap | Opponent attack | Evidence action | Argument / procedural action |
|---|---|---|---|---|---|---|---|

Rules:

1. Keep `confirmed`, `disputed`, `unknown` and `not-applicable` separate.
2. Do not convert a search-sample ratio into a probability of success.
3. An `A-` case must appear in the matrix unless it is demonstrably inapplicable.
4. A research output changes litigation strategy only through an identified variable, fact or evidentiary consequence; avoid decorative case citations.
5. If current law could change the value of an older case, require a `cn-law-hub` version check before relying on it.
6. Drafting follows only after material `evidence_gap` items have either an action, a deliberate risk acceptance, or a stop status.
