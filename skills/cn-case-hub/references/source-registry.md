# 免费官方案例来源登记表

## 来源权重

| 等级 | 来源 | 使用方式 | 限制 |
|---|---|---|---|
| A1 | 指导性案例、人民法院案例库入库参考案例官方材料 | 核心裁判规则与事实比较 | 仍需核验后续程序和法源变化 |
| A2 | 最高人民法院公报、最高法完整裁判或正式案例材料 | 高权重裁判理由 | 检查审级、后续裁判和时间适用 |
| B | 高级法院、专门法院、最高法官方典型案例 | 重要参考 | 典型案例可能匿名或缺全文 |
| C | 本地中院/基层法院等官方裁判材料 | 地域和事实比较 | 权重低于 A/B，不能用数量替代权重 |
| D | 搜索摘要、媒体、律所文章、商业数据库摘要 | 线索发现 | `lead-only`，不作正式依据 |

## 首选公开入口

1. 人民法院案例库：`https://rmfyalk.court.gov.cn/`
2. 最高人民法院：`https://www.court.gov.cn/`
3. 最高人民法院公报：`https://gongbao.court.gov.cn/`
4. 中国裁判文书网：`https://wenshu.court.gov.cn/`
5. 各级法院、专业法院官方站点：`*.court.gov.cn`、`*.chinacourt.gov.cn`
6. 多元解纷案例库：`https://dyjfalk.court.gov.cn/`（不得和法院裁判混同）

## 多轮校准

第一轮用法律术语；第二轮从命中案例提取法院实际用语；第三轮加入决定性事实、反向结果词和程序层级。每轮都记录新增关键词及理由，避免机械重复同一搜索式。

## 访问边界

登录、验证码、维护、robots、权限限制属于来源限制。记录后停止，不抓 Cookie、不绕过验证码、不模拟未授权接口。外部专业数据库可以作为实际研究环境，但不是本 Skill 的安装依赖。
